# ItzzFizz — Scroll-Driven Hero Section Animation

A scroll-driven hero section animation built with **React (Vite)**, **Tailwind CSS**, and **GSAP ScrollTrigger**.

## 🔗 Live Links

- **Live Webpage:** [https://sakshampratap8800.github.io/itzzfizz-hero/](https://sakshampratap8800.github.io/itzzfizz-hero/)
- **GitHub Repository:** [https://github.com/sakshampratap8800/itzzfizz-hero](https://github.com/sakshampratap8800/itzzfizz-hero)

## ✨ Features

- **Pinned Scroll Timeline (`pin: true`)** — The hero section stays locked in place while your scroll progress drives the entire animation sequence.
- **Staggered Letter Reveal** — `"WELCOME"` and `"ITZZFIZZ"` split into individual character spans that slide up and fade in smoothly.
- **Synchronized Orb & Trail** — A glowing orb travels across the track from start to finish in sync with the text and stats, leaving a glowing green trail behind it.
- **Impact Metrics Cards** — Stat cards animate in with a subtle stagger toward the end of the scroll sequence.
- **Smooth Scrubbing (`scrub: 1.5`)** — Motion interpolates smoothly with scroll position instead of feeling abrupt.

## 🛠️ Tech Stack

- React 19 + Vite
- Tailwind CSS
- GSAP + ScrollTrigger

## 🚀 Run Locally

```bash
npm install
npm run dev
```
